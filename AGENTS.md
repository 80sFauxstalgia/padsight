# PadSight

Public releases require maintainer approval. For local development and project setup, read `README.md`.

## Keep the instructions useful

When behavior, setup, commands or responsibilities change, update the affected README, task page and entry link in the same PR wherever they apply. Check paths and examples from a clean checkout.

When a correction, repeated failure or stale instruction exposes a gap, fix the immediate issue, identify its cause and check related paths. Make the smallest durable change to the owning rule, procedure or regression test. Exercise the original case and check the next comparable run. If the same failure recurs, revise the fix using that evidence. Rule changes follow the usual review and approval process.
